# Title
Bible club 

## Description 
This is a bible club web application that helps users in their spiritual journey helps them join sessions tied to a specific bible study and have reflections tied to specific bible study .

## Author 
- Cynthia Meikan
- Felix waweru 

## Features 
- Access to themed bible studies 
- creation for a session
- Creation of a reflection 

## Deployed app 
[Bibleclub](https://bible-club.onrender.com/)

## Technologies 
- React for frontend 
- flask(python) backend 
- Database SQLlite 
- styling css
- Deployment Render using pip + venv

## cloning 
``` bash 
git clone https://github.com/waweru-sdf/Bible-club
```

## Backend setup 
- cd server 
- pipenv install
- pipenv shell 
- flask db upgrade head 
- python seed.py 
- python app.py

## Frontend setup 
- cd client 
- npm install
- npm start
